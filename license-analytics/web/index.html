運転免許証データ分析（ブラウザ版）

サーバー不要でブラウザだけで動作します。合成データをこの端末内（IndexedDB）に生成し、集計・将来推計・画像生成はすべてブラウザ内で行います。地図・グラフ・推計は API キーなしで動作します。生成AI 分析だけは右上の「AI設定」で Anthropic API キーを設定すると有効になります。

生成する件数を選んでください（100万件は生成に 10〜30 秒、メモリ約 100MB）
