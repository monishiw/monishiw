# ミキホールディングス 日報入力アプリ

スーパーマーケットチェーン「ミキホールディングス」の店舗スタッフが、音声で日報を入力するための Web アプリです。`index.html` 1 ファイルだけで動作し、PC の Chrome / Edge、iPhone・Android のブラウザで使えます。インストールは不要です。

このリポジトリには、同じ作りの [家計簿アプリ](#家計簿アプリkakeiboindexhtml)（`kakeibo/index.html`）も入っています。

## 機能

- **店舗・名前の選択**（画面最上部）: 店舗は山手線全 30 駅の店舗。名前は「＋ 名前を追加…」で登録でき、次回から選択できます。
- **カレンダー**: 月送りで日付を選択。初期表示は今日。日報がある日には点が付きます。
- **マイクボタン**: タップして話すと、音声が文字になって日報欄に追記されます。もう一度タップで停止。
- **日報の表示・編集**: 画面下部に文字として表示。手入力での修正、保存、削除もできます。
- **過去の日報**: 選択中の店舗・名前の過去の日報を新しい順に一覧表示。タップで全文、もう一度タップでその日に移動。

## 本番（Vercel）

本番は Vercel で公開しています。GitHub の `nippo` ブランチが本番ブランチで、`nippo` にプッシュすると自動でデプロイされます。開発は `claude/dreamy-mendel-w2p2tt` ブランチで行い、本番に反映するときに `nippo` へ取り込みます。

## 公開方法（GitHub Pages を使う場合）

1. GitHub のリポジトリで **Settings › Pages** を開く
2. Source を「Deploy from a branch」、Branch を公開したいブランチ（例: `main`）の `/ (root)` にして保存
3. 表示された URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）をブラウザで開く

音声入力には HTTPS が必要です。GitHub Pages は HTTPS なのでそのまま使えます。

## 対応ブラウザ（音声入力）

| 環境 | 音声入力 |
| --- | --- |
| PC の Chrome / Edge | 使えます |
| iPhone / iPad の Safari | 使えます |
| Android の Chrome | 使えます |
| iPhone の Chrome、Firefox | 非対応（文字入力のみ） |

- 初回のマイク使用時に許可を求められます。拒否した場合はブラウザの設定でこのサイトのマイクを許可してください。
- iPhone で「ホーム画面に追加」した状態では、iOS のバージョンにより音声認識が動かないことがあります。その場合は Safari で直接開いてください。

## サンプルデータ

初回起動時に日報が 1 件もない場合、東京店（佐藤 花子）と西日暮里店（田中 健太）の 2026/9/1〜10/7 の日報がサンプルとして入ります。音声入力した文体で作成した架空の内容です。不要な場合は各日報を削除するか、`index.html` 内の `SEED` 配列を空にしてください。

## データの保存場所

日報・名前リストは端末の Safari 内（localStorage）に保存されます。別の端末や本部には送信されません。全店舗で共有・集計するにはサーバー（スプレッドシート連携など）の追加が必要です。

## 家計簿アプリ（`kakeibo/index.html`）

個人・家庭向けの家計簿 Web アプリです。日報アプリと同じく `kakeibo/index.html` 1 ファイルだけで動作し、スマホ・PC のブラウザで使えます。公開すると `https://<ドメイン>/kakeibo/` で開けます。

表示は暗め（ダーク）が標準です。右上の太陽／月ボタン、または「設定とデータ › 表示」でライト／ダーク／自動（端末の設定に合わせる）を切り替えられ、選択は端末に保存されます。

### 機能

- **月ナビ**（画面最上部）: 前の月・次の月に移動。月名をタップで今月に戻ります。
- **今月のまとめ**: その月の支出（大きな数字）、収入、収支、支出の前月比。予算を設定すると、使用率のメーターと「残り」「1日あたり使える額（残り日数で割った額）」が出ます。
- **記録する**: 支出／収入の切替、金額（全角数字・カンマ入りでも可）、カテゴリ（支出 12 種・収入 4 種）、日付、メモ。Enter キーでも追加できます。
- **カテゴリ別**: その月の内訳を円グラフ（ドーナツ型）と金額順の一覧で表示。円グラフは上位 6 カテゴリ＋「残り」で、中央に合計、タッチしたカテゴリの金額と割合が出ます。カテゴリごとに色が決まっていて、入力のチップや明細の丸印も同じ色です。円グラフや行をタップすると明細をそのカテゴリで絞り込みます。
- **月別の推移**: 直近 6 か月の収入・支出の棒グラフ。棒にタッチ（PC ではホバー）で数字が出て、タップでその月に移動。「表で見る」で同じ数字を表にします。
- **明細**: 日ごとにまとめた一覧（日曜は赤、土曜は青）。タップで編集・削除。削除は「元に戻す」で取り消せます。
- **設定とデータ**: 月の予算、CSV（Excel 用、BOM 付き UTF-8）と JSON バックアップの書き出し、バックアップの読み込み（追加・同じ ID は上書き）、サンプルデータの投入と削除、全データ削除（2 段階確認）。

### カテゴリ

| 種別 | カテゴリ |
| --- | --- |
| 支出 | 食費、日用品、交通、住居、水道光熱、通信、医療、教育、衣服・美容、娯楽、交際、その他 |
| 収入 | 給与、賞与、副収入、その他 |

カテゴリを変えたいときは `kakeibo/index.html` 内の `EXP_CATS` / `INC_CATS` を編集してください（`id` は保存データのキーになるので、既存の `id` を変えると過去の記録が読めなくなります）。

### サンプルデータ

記録が 1 件もないときは、明細欄に「サンプルデータで試してみる」ボタンが出ます。押すと直近 3 か月分の架空の記録（給与・家賃・食費など）が入り、明細に「サンプル」の印が付きます。「設定とデータ › サンプルだけ消す」で、サンプルだけをまとめて消せます。自動では入りません。

### データの保存場所

記録と予算は端末のブラウザ内（localStorage、キー `kakeibo-v1`）に保存され、どこにも送信されません。別の端末に移すときは「バックアップ（JSON）」を書き出して、移動先で読み込んでください。
