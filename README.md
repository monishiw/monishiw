# ミキホールディングス 日報入力アプリ

スーパーマーケットチェーン「ミキホールディングス」の店舗スタッフが、iPhone から音声で日報を入力するための Web アプリです。`index.html` 1 ファイルだけで動作します。

## 機能

- **店舗・名前の選択**（画面最上部）: 店舗は山手線全 30 駅の店舗。名前は「＋ 名前を追加…」で登録でき、次回から選択できます。
- **カレンダー**: 月送りで日付を選択。初期表示は今日。日報がある日には点が付きます。
- **マイクボタン**: タップして話すと、音声が文字になって日報欄に追記されます。もう一度タップで停止。
- **日報の表示・編集**: 画面下部に文字として表示。手入力での修正、保存、削除もできます。
- **過去の日報**: 選択中の店舗・名前の過去の日報を新しい順に一覧表示。タップで全文、もう一度タップでその日に移動。

## 公開方法（GitHub Pages）

1. GitHub のリポジトリで **Settings › Pages** を開く
2. Source を「Deploy from a branch」、Branch を公開したいブランチ（例: `main`）の `/ (root)` にして保存
3. 表示された URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を iPhone の **Safari** で開く

音声入力には HTTPS が必要です。GitHub Pages は HTTPS なのでそのまま使えます。

## iPhone での注意

- 音声入力は **Safari** で開いてください（iPhone の Chrome など他ブラウザは音声認識 API 非対応のため、文字入力のみになります）。
- 初回のマイク使用時に許可を求められます。拒否した場合は「設定 › Safari › マイク」で許可してください。
- 「ホーム画面に追加」した状態では iOS のバージョンにより音声認識が動かないことがあります。その場合は Safari で直接開いてください。

## データの保存場所

日報・名前リストは端末の Safari 内（localStorage）に保存されます。別の端末や本部には送信されません。全店舗で共有・集計するにはサーバー（スプレッドシート連携など）の追加が必要です。
